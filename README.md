# home-game-ledger
https://waynevnguyen.github.io/home-game-ledger
Track buy-ins, payments and cash-outs. Check the table adds up

## Features
- Add players and record multiple buy ins and buy out
- Track if players have paid (via cash, venmo, zelle)
- Indicate who is the bank and who they need to pay/request
- Simplify payments by having the losers pay the winners
- Check that it is a zero sum game (buy ins == buy outs)
- Format a summary of the game and payments
- Save the data in the browser so info is not loss on refresh
